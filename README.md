# bitcoin-sentiment-trader-analysis
# Bitcoin Market Sentiment vs Trader Performance

## Objective
Analyze the relationship between Bitcoin Fear & Greed Index sentiment and Hyperliquid trader performance.

## Datasets
- Bitcoin Fear & Greed Index
- Hyperliquid Historical Trading Data

## Methodology
1. Data Cleaning
2. Timestamp Conversion
3. Dataset Merging
4. Exploratory Data Analysis (EDA)
5. Sentiment-based Performance Evaluation

## Key Findings

### Average Profitability (Closed PnL)
| Sentiment | Average PnL |
|------------|------------:|
| Extreme Greed | 67.89 |
| Fear | 54.29 |
| Greed | 42.74 |
| Extreme Fear | 34.54 |
| Neutral | 34.31 |

### Win Rate
| Sentiment | Win Rate (%) |
|------------|------------:|
| Extreme Greed | 46.49 |
| Fear | 42.08 |
| Neutral | 39.70 |
| Greed | 38.48 |
| Extreme Fear | 37.06 |

### Trading Volume
Fear periods showed the highest average trade volume (~7816 USD), indicating increased trader activity during uncertain market conditions.

## Visualizations
The repository includes:
- Sentiment Distribution
- PnL Distribution by Sentiment
- Top 10 Traders Analysis

## Conclusion
Market sentiment has a measurable impact on trader behavior and profitability. Extreme Greed periods generated the highest average profits and win rates, while Fear periods exhibited the highest trading activity.
